Urdu Text to PDF

Apna Urdu ya English matn likhein ya paste karein, phir browser ke Print option se PDF save kar lein.

Button dabane ke baad Print window khulegi. Printer/Destination mein “Save as PDF” select karein. Text aapke browser mein hi rehta hai.

Upload InPage File (.inp)

Apni InPage file select karein. Tool file ko aapke browser mein read karega aur milne wala Urdu text neeche text box mein daal dega. Aap PDF banane se pehle text check aur edit kar sakte hain.

Maximum file size: 50 MB. File server par upload nahi hoti.

Urdu Document

PDF banane se pehle apna matn upar wale box mein tayyar karein.

Privacy & usage

This tool uses your browser's built-in print function. InPage file reading runs locally in your browser using open-source parsing libraries loaded from a CDN. Your selected file and text are not uploaded to UrduDigitalHub. An internet connection is required to load the parser.
